# Brand assets (proposal)

Status: proposal written 2026-10-11. The owner signs off logos.

- `logo.svg` / `logo-dark.svg`: the mark, 64x64 units. It is the product plan view: six rounded-square keys in a 2x3 block, the knob as a solid disc where the layout puts it (right of the second row), and below them a right-triangle wedge. The wedge's slope is exactly 15 degrees (53 wide, 14.2 tall): the desk angle from the spec.
- `wordmark.svg` / `wordmark-dark.svg`: mark plus "Helm" in a bold sans (Liberation Sans Bold), converted to outlines.
- Colours: ink `#14202B` on `#EEF2F4`; accent `#B5361A` (5.3:1 on paper). Dark: `#E6EDF2` on `#0F161C`, accent `#FF8F6B` (8.2:1). See `DESIGN.md`.
- Previews in `preview/`, rendered with `resvg` and optimised with `oxipng`.
