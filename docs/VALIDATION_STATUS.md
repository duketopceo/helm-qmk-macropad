## Status definitions

- VERIFIED_REPO: inspected directly in repository files.
- VERIFIED_SOURCE: confirmed in a manufacturer or authoritative source, with URL and access date recorded.
- BUILD_VERIFIED: reproduced through a recorded successful build.
- PHYSICALLY_VERIFIED: tested on the actual hardware, with a dated record.
- ASSUMPTION: plausible but not confirmed.
- BLOCKED: cannot proceed without specified evidence or owner action.

### 3. What conflicts / needs reconciliation
1. Insert OD: BOM.md says "~3.5 mm OD, length 3-4 mm"; CAD `m2_insert = 3.2 mm` (hole to be drilled, not necessarily insert OD). Installing a 3.5 mm insert in a 3.2 mm hole in PETG will melt a larger hole, not a drop-in fit. BLOCKED until the selected insert's OD + supplier install guidance + coupon test are recorded. Do not declare compatible/incompatible.
2. XIAO depth: CAD pocket is 17.7 mm long x 1.2 mm deep; Seeed lists 21 x 17.8 mm; a 17.8 mm board in a 17.7 mm insert will interfere by 0.1 mm if oriented the same way. Pocket CAD uses depth * cos(15) = 17.09 mm in the desk-parallel direction. Tolerance stack needs a printed fit test. ASSUMPTION: clears due to shrinkage/layer tolerance; NOT verified.
3. Encoder: BOM says "~7 mm bushing"; CAD is 7.2 mm; Adafruit 377 (PEC11 family) is threaded but specific bushing/nut dims not confirmed from a drawing in this audit. Nut across-flats vs 9.0 mm plate-edge clearance (computed from CAD) is not verified. BLOCKED.
4. Firmware provenance: checked-in UF2 has NO commit hash, compiler version, qmk version, or build log in the repo. Cannot be reproduced or trusted as current. BLOCKED for reproducibility.
5. README vs CAD scale: README says "Plate ~75x65 mm; desk footprint ~75x62 mm; rear wall ~26 mm." CAD derived: 75.12 x 64.60 plate, 62.40 desk depth, 25.72 rear height. Consistent (rounding). No action.
6. keyboard.json URL field is `https://github.com/duketopceo/helm` but actual repo is `duketopceo/helm-qmk-macropad`. Minor inconsistency; fix when next touching firmware (kept as-is to avoid scope creep in this audit).
